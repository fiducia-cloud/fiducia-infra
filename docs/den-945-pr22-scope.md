# DEN-945 PR #22 scope boundary

PR #22 is limited to the reproducible three-member NATS/JetStream substrate:
route topology, mTLS secret contract, private network exposure, persistent local
storage, immutable images, readiness/drain behavior, delivery policy, evidence
validation, tests, and operator documentation.

It does not claim physical deployment, customer traffic, successful live
failover, restored backups, real certificate issuance, measured WAN behavior, or
production launch approval. Those remain Linear evidence gates.
